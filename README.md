הבעיה העסקית
המערכת צריכה לענות כמה נסיעות יצאו מתחנה וכמה הגיעו אליה ביום מסוים.
מקור הנתונים
קובצי ZIP/CSV ציבוריים של Citi Bike, המתגלים באמצעות רשימת XML של S3.
השכבות

- Bronze — קובצי המקור הגולמיים ו־provenance.
- Silver — נסיעות אחידות ותקינות.
- Quarantine — רשומות שאינן ניתנות לספירה.
- Gold — אירועי תחנה ואגרגציה יומית.
- Report — תשובת JSON לשאלה העסקית.

מגבלות חשובות
- רק ingestion ניגש לאינטרנט.
- כל job עצמאי.
- העיבוד הוא לפי window.
- הרצות חוזרות הן idempotent.
- שינוי schema מזוהה לפי header.
- חלון שגוי נכשל לפני כתיבה.
- Bronze נשמר בקבצים מקומיים ולא ב־PostgreSQL.

אין צורך לתאר עדיין שמות טבלאות או פונקציות.
